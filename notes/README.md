# Working notes (historical)

<!-- aq:historical -->
> **Historical working notes.** Dated scratch material, kept for the record and
> never revised. Not instructions, not procedures to follow. Start at
> [the documentation home](../docs/README.md).

These are an operator's and an agent's notes from earlier in the project:
research before a feature, a test-failure triage from a specific run, a
procedure written down before it became code. Several describe things that no
longer exist — the Discord control UI, the old profile set, tool gaps that have
since been filled.

Where a note describes a procedure that now ships as a command, the command is
the current answer. `aq doctor` replaced the hand-written health checks;
[Troubleshooting worker sessions](../docs/guides/session-troubleshooting.md)
replaced the stuck- and blocked-task procedures.
