# `sdd/` — per-task working evidence

<!-- aq:historical -->
> **Immutable evidence, preserved unedited.** See
> [the parent index](../README.md) for what this directory is and
> [the documentation home](../../docs/README.md) for current documentation.

One directory per feature, named `YYYY-MM-DD-<slug>`. Inside, the convention is
`task-<n>-brief.md` (what the task was), `task-<n>-report.md` (what was done) and
`task-<n>-review.md` (what the reviewer said), with a `progress.md` tying them
together.
