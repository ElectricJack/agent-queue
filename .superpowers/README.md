# Spec-driven-development working evidence (historical, unedited)

<!-- aq:historical -->
> **Immutable evidence.** This is the per-task working record of two large
> features: briefs, reports, reviews and progress logs written by the agents that
> built them. Preserved exactly as produced. Start at
> [the documentation home](../docs/README.md).

This directory is *process* evidence, not documentation. It exists because those
two features were built task-by-task with a written brief, a report and a review
per task, and throwing that away would lose the only account of why several
non-obvious decisions were made.

Nothing here describes current behaviour, and nothing here is a procedure to
follow. The design and plan documents these tasks worked from are in
[`docs/superpowers/`](../docs/superpowers/README.md); the current explanations
are under [`docs/concepts/`](../docs/concepts/).
