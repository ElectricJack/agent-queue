# Tutorials

These two tutorials are the newcomer path for [Agent Queue](../README.md).
Start with [install and start AQ](install.md), then use [your first isolated
task](first-task.md) to create a disposable repository and watch one worker
complete it.

They describe current shipped behaviour. For terminology, keep the
[glossary](../reference/glossary.md) nearby; for an existing repository or a
GitHub clone, use the more complete [project onboarding guide](../guides/project-onboarding.md).
