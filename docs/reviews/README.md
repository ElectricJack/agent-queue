# Code and merge reviews (historical, unedited)

<!-- aq:historical -->
> **Immutable evidence.** Each file is one review as it was written, on the date
> in its name. Preserved unedited. Start at
> [the documentation home](../README.md).

These are individual review write-ups kept as the record of a decision — what a
reviewer asked for, what was accepted, what was waived. They are not a review
process description: AQ ships **no automatic reviewer creation**. The default
pipeline creates no per-task reviewers, no final branch reviewers and no review
gates on downstream work; a review stage is something a project can configure,
not something the shipped defaults produce. See
[Playbooks V2](../concepts/playbooks.md) and
[Integration](../concepts/integration.md).
