**Direct AQ tickets** match the stored branch name or canonical aq/<task-id> name. **Related AQ tickets** are explicitly labelled associations from the earlier investigation (operator snapshots, backup aliases, or integration checkpoints); they are not separate tickets owning that branch. Review tickets are matched by the implementation task title. All ticket states were read from current and archived AQ records for this document.

**COMPLETED does not mean merged or approved.** A completed review may contain a rejection, and an approved older commit does not approve a newer tip. Review-state columns expose all matched historical/current review records; existing exact-tip approval evidence supports the first merge list below. A missing ticket means no association was established, not proof the branch has no useful work.
