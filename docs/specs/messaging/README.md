# Messaging platform specs (historical)

<!-- aq:historical -->
> **Superseded design record.** Both specs here describe the messaging platform
> AQ had before the 2026-09-08 Discord simplification. Neither describes current
> behaviour. Read [Messaging, digests and escalations](../../concepts/messaging.md).

| Spec | Status |
|---|---|
| [`base.md`](base.md) | Superseded in part. The platform-abstraction layer it defines was reduced to one notification-only transport. |
| [`discord.md`](discord.md) | Superseded. The per-project channels, per-task threads, gate buttons, slash commands and modals it specifies were all removed. |

A third spec, `telegram.md`, was deleted with the Telegram adapter. Links to it
in other historical pages are left as plain text rather than repaired.

See [the historical index](../../history/README.md) and
[the disposition ledger](../../history/disposition-ledger.md).
