## 2. Database

### 2.1 `sessions` table (`src/database/tables.py`)

```python
sessions = Table(
    "sessions",
    metadata,
    Column("id", Text, primary_key=True),                    # uuid4 hex
    Column("task_id", Text, ForeignKey("tasks.id"), nullable=True),   # NULL for named
    Column("project_id", Text, ForeignKey("projects.id"), nullable=False),
    Column("profile_id", Text, nullable=False),              # soft ref, like agents.profile_id
    Column("harness", Text, nullable=False),                 # e.g. "claude"
    Column("provider", Text, nullable=False),                # "tmux" | "subprocess" | "fake"
    Column("name", Text, nullable=False),                    # "s-<task_id>" | "n-<profile>[--<pid>]"
    Column("lifecycle", Text, nullable=False),               # "task" | "named"
    Column("state", Text, nullable=False, server_default="'starting'"),
    Column("session_key", Text, nullable=True),              # harness resume key
    Column("work_dir", Text, nullable=False),
    Column("epoch", Text, nullable=False),                   # AQ_DAEMON_EPOCH at launch
    Column("instance_token", Text, nullable=False),          # AQ_INSTANCE_TOKEN (kill fence)
    Column("started_at", Float, nullable=False),
    Column("last_activity", Float, nullable=True),
    Column("restarts", Integer, nullable=False, server_default="0"),
    Column("quarantined_at", Float, nullable=True),
    Column("sleep_reason", Text, nullable=True),
    Index("idx_sessions_task_id", "task_id"),
    Index("idx_sessions_state", "state"),
    Index("idx_sessions_name", "name"),
)
```

`state` values: `starting | running | draining | stopped | sleeping | quarantined`.
Stalled is derived (lease TTL vs `last_activity`), never stored.

### 2.2 Alembic

```bash
alembic revision --autogenerate -m "add sessions table"
```

Notes: plain `Text/Integer/Float` types only — both dialects handle them; no `JSONB`, no
partial indexes, no `ALTER … USING`. Server defaults are strings quoted in the existing
house style (`server_default="'starting'"`). Review the autogenerated file: Alembic must
emit `op.create_table` + three `op.create_index` calls and nothing else (it sometimes picks
up unrelated drift — reject that). Downgrade drops the table. Verify on both backends with
`pytest tests/test_database.py -v` and the PG job (`tests/test_database_postgresql.py`).

## 3. Key Classes and Signatures

### 3.1 `src/sessions/provider.py`

```python
class Cap(StrEnum):
    ATTACH = "attach"; PEEK = "peek"; NUDGE = "nudge"; ACTIVITY = "activity"; RELAUNCH = "relaunch"

@dataclass(frozen=True)
class SessionSpec:
    session_name: str
    work_dir: str
    command: list[str]                  # argv; agent is the pane's initial process
    env: dict[str, str]                 # includes AQ_* markers; CLAUDECODE etc. stripped
    prompt: str | None                  # None when prompt_mode == "none"
    prompt_mode: str                    # "arg" | "flag" | "none"
    ready_delay_ms: int
    ready_prompt_prefix: str | None
    process_names: tuple[str, ...]
    lifecycle: str                      # "task" | "named"
    dialogs: tuple[DialogRule, ...]
    skip_escape_before_enter: bool

@dataclass(frozen=True)
class SessionHandle:
    name: str
    provider: str
    instance_token: str

class NotSubmitted(Exception): ...          # nudge pasted but Enter unconfirmed → re-queue
class PartialListError(Exception):          # list_running failed mid-way; carries partial
    def __init__(self, partial: list[SessionHandle], cause: Exception): ...
class SessionDiedDuringStartup(Exception):  # carries start_stderr_path

class SessionProvider(ABC):
    name: ClassVar[str]
    capabilities: ClassVar[frozenset[Cap]]

    @abstractmethod
    async def start(self, spec: SessionSpec) -> SessionHandle: ...
    @abstractmethod
    async def stop(self, h: SessionHandle, *, grace: float = 2.0) -> None: ...
    @abstractmethod
    async def interrupt(self, h: SessionHandle) -> None: ...
    @abstractmethod
    async def is_running(self, h: SessionHandle) -> bool: ...
    @abstractmethod
    async def process_alive(self, h: SessionHandle, process_names: tuple[str, ...]) -> bool: ...
    @abstractmethod
    async def list_running(self, prefix: str) -> list[SessionHandle]: ...
    @abstractmethod
    async def nudge(self, h: SessionHandle, text: str) -> None: ...
    @abstractmethod
    async def peek(self, h: SessionHandle, lines: int = 60) -> str: ...
    @abstractmethod
    async def last_activity(self, h: SessionHandle) -> float | None: ...
    @abstractmethod
    async def attach_command(self, h: SessionHandle) -> str: ...
    @abstractmethod
    async def set_meta(self, h: SessionHandle, key: str, value: str) -> None: ...
    @abstractmethod
    async def get_meta(self, h: SessionHandle, key: str) -> str | None: ...
```

`SessionProviderRegistry` in `src/sessions/__init__.py` follows `RuntimeRegistry`
(`src/runtimes/__init__.py`): `get(name)`, `names()`, `create(name, config)`;
`default_session_registry()` registers `tmux`, `subprocess`, `fake`.

### 3.2 `src/sessions/tmux.py` — TmuxProvider

`capabilities = frozenset({Cap.ATTACH, Cap.PEEK, Cap.NUDGE, Cap.ACTIVITY, Cap.RELAUNCH})`.
Every invocation is `tmux -u -L {socket} <sub…>` via one helper:

```python
async def _tmux(self, *args: str, timeout: float = 30.0) -> str   # asyncio.create_subprocess_exec
```

(never `subprocess.run` — async-first). Internal methods, each mapping to design §5.1:

- `_probe_server(self) -> bool` — `has-session -t =__aq_probe__` before every create.
- `start()` — `new-session -d -s <name> -c <work_dir> -e K=V … '<argv>'`; prompt > 1024 B →
  temp file under `<work_dir>/.aq/tmp/` + `sh -c '… exec <cmd> "$__aq_prompt"'`; then
  `set-option -wt <name> window-size latest`, `remain-on-exit on`, `mouse off`,
  `monitor-activity off`; then `_await_ready()`.
- `_await_ready(self, h, spec) -> None` — poll `display-message -p '#{pane_current_command}'`
  (100 ms) until non-shell; then `ready_delay_ms` sleep or 200 ms `capture-pane` poll for
  `ready_prompt_prefix` with NBSP (` `) normalization; budget
  `clamp(ready_delay_ms + 5000, 5000, 60000)` ms; on pane death write last capture to
  `<state_dir>/sessions/<name>/start-stderr.log` and raise `SessionDiedDuringStartup`;
  interleave `run_dialog_dismissal()` before and after the prefix wait.
- `nudge()` — `asyncio.Lock` per session name; `_find_agent_pane()` via
  `list-panes -F '#{pane_id}\t#{pane_current_command}'` matched against `process_names`;
  cancel copy-mode (`#{pane_in_mode}` → `send-keys -X cancel`); `send-keys -l` ≤ 4096 B else
  `load-buffer` + `paste-buffer -p -d`; debounce `nudge_debounce_ms`; optional `Escape`
  per `skip_escape_before_enter`; `Enter` + busy-indicator poll (4 × 150 ms), retry ≤ 3;
  raise `NotSubmitted`.
- `stop()` — pane pid → descendants + process group → SIGTERM, `grace` (2 s), SIGKILL →
  `kill-session -t`; every signal fenced by `proctable` start-time check and
  `AQ_INSTANCE_TOKEN` match.
- `peek()` — `capture-pane -p -t <name> -S -<lines>`.
- `last_activity()` — max `#{window_activity}` with poke discounting: activity within 3 s of
  our own last send is reported as the pre-poke value.
- `is_running` / `process_alive` / `list_running` — served from `TmuxStateCache`
  (`state_cache.py`): one `list-panes -a -F '#{session_name}\t#{pane_dead}\t#{pane_pid}'` +
  one `ps -eo pid,ppid,comm,args` per tick, TTL 2 s; `ps` failure ⇒ `process_alive` returns
  True (optimistic); tmux "no server" ⇒ `list_running` raises `PartialListError` with
  last-known-good — callers must treat unknown ≠ dead.
- `set_meta`/`get_meta` — `set-environment -t` / `show-environment -t`.

### 3.3 `src/sessions/subprocess.py` and `fake.py`

### 3.6 `src/sessions/reconciler.py` — SessionReconciler

```python
class SessionReconciler:
    def __init__(self, db, config, providers: SessionProviderRegistry,
                 harnesses: HarnessRegistry, spec_builder: SessionSpecBuilder,
                 bus: EventBus, command_handler_getter): ...

    async def adopt_on_start(self) -> AdoptReport: ...   # boot-time pass
    async def tick(self) -> None: ...                    # cascade step, every cycle
```

`tick()` runs, in order (each step isolated with try/except, events on every transition):

1. **Refresh observation** — one `list_running` per prefix + state-cache tick; update
   `last_activity` from provider and transcript watcher.
2. **Drain-ack handling** — sessions with meta `AQ_DRAIN_ACK=1` (set by
   `_cmd_session_drain_ack`): verify task closed → `stop()` (fenced) → state `stopped` →
   `session.drain_acked`. Task still open → treat as premature drain: nudge once, then
   exit-classify.
3. **Exit classifier** — rows in `running`/`starting` whose process is dead:
   `classify_exit(session, task, last_peek) -> ExitVerdict` (`src/sessions/exit_classifier.py`;
   verdicts `RATE_LIMIT | RAPID_CRASH | PRODUCTIVE_DEATH | DRAINED`), then apply: PAUSED +
   cooldown / backoff restart (`bump_session_restarts`, quarantine when `restarts >=
   max_restarts` within `restart_window_seconds`) / `needs_attention` per retry policy.
4. **Stall ladder** — `running` task sessions with `now - last_activity > lease_ttl_seconds`
   and no recent `aq task heartbeat`: nudge → backoff ×`stall_max_nudges` → interrupt +
   restart with resume → quarantine. Rung state kept on task_metadata keys
   (`stall_nudges`, `stall_last_action_at`); events `task.stalled/nudged/restarted/quarantined`.
5. **Named desired-state** — build desired set from profiles with `lifecycle: named`;
   start/wake missing (respecting `wake_mode`), drain idle past `idle_timeout`
   (state `sleeping`), recycle past `max_session_age + jitter` via handoff (invoke
   `aq handoff` semantics through CommandHandler, then kill + relaunch with resume).
6. **Backstop** — `stuck_timeout_seconds` exceeded end-to-end → force-kill + exit-classify.

`adopt_on_start()`: `list_running("s-") + list_running("n-")`, cross-checked with
`proctable.scan_by_env_marker("AQ_SESSION_ID")`; live matches → rebind (update `epoch`,
keep task IN_PROGRESS, emit `session.adopted`); dead rows → step 3; unknown live sessions
whose `AQ_API_URL` matches this daemon → adopt-or-kill by whether the task exists.
`PartialListError` aborts adoption for that prefix (defer, don't reap).

### 3.7 Transcripts (`src/sessions/transcripts/`)

```python
@dataclass(frozen=True)
class TranscriptEntry:
    uuid: str; parent_uuid: str | None; type: str      # user|assistant|system|tool_use|tool_result
    text: str; model: str | None; usage: dict | None; ts: float

class TranscriptReader(ABC):
    harness: ClassVar[str]
    @abstractmethod
    def resolve_path(self, work_dir: str, session_key: str | None) -> Path | None: ...
    @abstractmethod
    async def read_new(self, path: Path, offset: int) -> tuple[list[TranscriptEntry], int]: ...
    def infer_activity(self, tail: list[TranscriptEntry]) -> str: ...   # "in-turn" | "idle"
```

`ClaudeTranscriptReader.resolve_path` slugs `work_dir` (`/` and `.` → `-`) into
`~/.claude/projects/<slug>/`, picks by `session_key` when known else newest mtime.
`TranscriptWatcher` polls every `transcript_poll_seconds` (2 s): new entries →
`bus.emit("notify.task_message", TaskMessageEvent(..., stream_id=session_id))` (the
existing per-stream Discord worker consumes these unchanged); `usage` deltas →
`db.record_token_usage(project_id, agent_id_or_session, task_id, tokens)`; `in-turn` →
`touch_session_activity` + `agents.last_heartbeat`. Missing path → one-shot
`session.transcript_missing` event, fall back to peek-diff.

## 6. Feature Flag and Rollout (dual-run)

1. `sessions.enabled: false` ships first — all new code dormant, tests green.
2. Routing rule in `_execute_task`: session path iff `sessions.enabled` **and** the resolved
   profile has `harness:` set. Profiles without `harness` keep `runtime: claude_sdk|acpx`
   verbatim. This gives per-profile, per-project opt-in (project-scoped profile overrides).
3. Dual-run on one test project: a scoped profile with `harness: claude` runs the same task
   mix as a `claude_sdk` profile; compare outcomes, tokens (ledger), wall time, and
   intervention counts for ≥ 1 week.
4. Flip shipped default profiles to `harness: claude`; `default_runtime: session`.
5. Deletion phase: remove `src/runtimes/claude_sdk.py`, `src/runtimes/acpx.py`,
   `src/runtimes/_subprocess.py`, the `claude-agent-sdk`/`acpx` deps (pyproject + `setup.sh`),
   and `VALID_RUNTIMES` entries; `src/runtimes/supervisor.py` stays dormant
   ([[design/feature-pauses]] owns its fate). `Runtime` ABC + registry shrink to the
   supervisor singleton until the playbook comeback decides.

Rollback at any point before step 5 is `sessions.enabled: false` (or removing `harness:`
from one profile); live sessions drain naturally — `aq session kill` cleans stragglers.

## 10. Risks and Mitigations

- **Pane scraping drift across harness versions.** Confined to readiness/dialogs/submit
  confirmation; all patterns live in vault harness files (hot-editable, no release);
  goldens catch regressions. Escape hatch: structured-socket provider (deferred).
- **Completion protocol non-compliance** (agent exits without `aq task close`). Exit
  classifier guarantees no task is silently lost; `needs_attention` + transcript makes the
  failure diagnosable; prompt templates and `aq prime` repeat the protocol.
- **Adoption mis-binding** after restart. Double-keyed identity (env markers + instance
  token) and refuse-on-partial-list; worst case is a quarantined session, never a
  wrong-task kill.
- **tmux version variance** (3.3–3.7 flag/binding drift). Pin minimum tmux ≥ 3.3 in
  `aq doctor`; confirm effects by querying tmux, never by matching stderr wording.
- **Dual-run divergence** (session path completes differently from SDK path). The
  comparison window in §6.3 is the gate; both paths share `_run_completion_pipeline`, so
  divergence is confined to launch/observe/close.
- **Windows dev machines.** The daemon already targets Linux/WSL2; `fake` +
  `subprocess` keep the test suite runnable on Windows, tmux tests are marker-gated.
- **Token ledger accuracy** from transcripts vs SDK usage callbacks. Dual-run compares
  ledger totals; transcript `usage` fields are the same source the SDK reports from.
