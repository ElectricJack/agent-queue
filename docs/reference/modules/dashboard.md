# Dashboard module catalog

This shard covers every production module assigned to the **dashboard** documentation area: the React/Vite UI under `dashboard/src/` and the separately running `src/editor/` utility. It is the exhaustive companion to the user-first [Dashboard guide](../../guides/dashboard.md). Paths under `__tests__/`, package/build configuration, and generated clients are intentionally outside this production-module table; see the guide for their role and checks.

> **Boundary.** A catalog row says which family explains a module; it does not mean every module owns persistent data. The daemon owns API data, worktrees, sessions, vault content, and database records. The browser owns routes, cached query data, transient UI state, and limited local preferences. `src/editor/` has no current `dashboard/src` import and is labelled backend-only below.

Start with the [Dashboard guide](../../guides/dashboard.md) for UI behavior and architecture, then use this table to find the file family. All dashboard HTTP calls should flow through [dashboard/src/api/client.ts](../../../dashboard/src/api/client.ts) and the generated client; live updates flow through [dashboard/src/ws/useEventStream.ts](../../../dashboard/src/ws/useEventStream.ts).
