# Module catalog — contributing

The coverage shard for **contributor setup, testing, builds and release
tooling**. It carries no production modules: the running system contains none
of these files. What it does carry is the 44 supporting files — packaging, CI,
scripts, development environment — three agent-facing instruction files, and
the 771-path test tree, which is covered as a layout rather than file by file.

Prose for everything here lives under [`docs/contributing/`](../../contributing/README.md).
The index for every other shard is the [module catalog](README.md).

| Column | Meaning |
|---|---|
| Module | The source path, as a relative link. |
| Purpose | One sentence, present tense: what it does. |
| Component | The page that explains it in prose. |
| Notes | Tests that cover it, or a caveat worth carrying. |

| [`docker-compose.yml`](../../../docker-compose.yml) | Runs the disposable PostgreSQL 18 the test suite builds throwaway databases in, on host port 5533 with tuned `shared_buffers`/`work_mem` and a `pg_isready` healthcheck. | [setup](../../contributing/setup.md#postgresql-for-tests) | Never the daemon's database. `docker compose down -v` removes the volume. |

| [`.pre-commit-config.yaml`](../../../.pre-commit-config.yaml) | Two `ruff-pre-commit` hooks — `ruff-format`, then `ruff --fix`. | [checks](../../contributing/checks.md#lint) | Opt-in: `pre-commit install`. Nothing in CI runs it. |
| [`.vibecop.yml`](../../../.vibecop.yml) | Ignore list for the `aq-vibecop` plugin's code-quality scans: generated clients, `docs/`, `scripts/` and vendored trees. | [scripts](../../contributing/scripts.md#historical-and-unsupported) | Excludes `packages/aq-client/**` because findings there need a generator change, not an edit. |
| [`.mcp.json`](../../../.mcp.json) | Offers one MCP server, `agent-queue`, over HTTP at `localhost:8082/mcp`, to MCP-aware editors and agent CLIs working in this repository. | [setup](../../contributing/setup.md#editor-and-agent-configuration) | Useful only with a daemon running. |

| [`uninstall.sh`](../../../uninstall.sh) | Returns the checkout to a fresh-clone state and optionally removes `~/.agent-queue/`. | [setup](../../contributing/setup.md#install) | Destructive. Re-execs from a temporary copy so `git clean` cannot delete it mid-run. |

## Test tree

Tests are covered as a layout and a set of markers, not file by file — 771
tracked paths, in these groups. The prose is [testing](../../contributing/testing.md).

| Group | Files | What it holds |
|---|---|---|
| [`tests/conftest.py`](../../../tests/conftest.py) | 1 | The DSN preflight, the production-database fence, the autouse PostgreSQL lease pool, and the `disable_schema_cache`, `unpooled_postgres`, `perf_strict` and `claude_cli_*` fixtures. |
| [`tests/db_fixtures.py`](../../../tests/db_fixtures.py) | 1 | The template database, the per-worker lease pool, and truncate-plus-seed reset. Three tiers: lease, clone, scratch. |
| [`tests/pg_dsn.py`](../../../tests/pg_dsn.py) | 1 | Per-xdist-worker DSN derivation, owned-database creation, and disposal at session finish. |
| `tests/*_helpers.py` | 6 | Imported, not collected: Git mocks, Playbook V2 builders, session dispatch, assignment routing, PostgreSQL trigger helpers. |
| [`tests/playbook_fixture_activation.py`](../../../tests/playbook_fixture_activation.py) | 1 | Discovers the mechanically complete Playbooks V2 artefact fixtures under `tests/fixtures/playbooks/` by reading each bundle's `manifest.md` frontmatter. |
| `tests/test_*.py` | 549 | One file per area. The file for a module is normally `tests/test_<area>.py`. |
| [`tests/perf/`](../../../tests/perf/) | 7 | Statement-count and latency budgets, all marked `perf`; wall-clock ones also need `AQ_PERF_STRICT=1`. |
| [`tests/llm/`](../../../tests/llm/) | 10 | LLM client, spec, provider adapters and a fake `genai` transport. |
| [`tests/task_graph/`](../../../tests/task_graph/) | 15 | Graph commands, layout queries, dirty marks and the driver, plus the layout engine's own eight files under `layout/`. |
| [`tests/fixtures/`](../../../tests/fixtures/) | 179 | Data, not tests: `contracts/`, `fake_gh/`, `formulas/`, `harnesses/`, `playbooks/`, `task_graphs/`, `transcripts/`. |
| [`tests/__init__.py`](../../../tests/__init__.py) | 1 | Makes `tests` importable so helpers can be imported by module path. |

`pyproject.toml`'s `testpaths` also names `packages/`, which currently contains
only the two generated clients and no tests.
