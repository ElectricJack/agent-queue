# Plans

This directory holds multi-ticket plans: the scope, the child tasks and the
dependency graph for a body of work, recorded before the work starts.

A plan is **proposed work**, never a description of shipped behaviour. Read one
to understand what a group of tickets is trying to achieve; read
[`docs/concepts/`](../concepts/) for what AQ does today.

| Plan | State | What it covers |
|---|---|---|
| [`documentation-overhaul/`](documentation-overhaul/README.md) | In flight (AQ epic `solid-grove`) | This documentation overhaul: the beginner hierarchy, page ownership, the module coverage manifest and the known-inaccuracies ledger. |
| [`install-onboarding/`](install-onboarding/README.md) | Proposed (AQ epic `noble-apex`) | A seamless install and first-project onboarding path. Not yet built. |

Older plans live under [`docs/superpowers/plans/`](../superpowers/plans/README.md),
one per feature. Those are historical.

Every file here has a recorded disposition in
[the disposition ledger](../history/disposition-ledger.md).
