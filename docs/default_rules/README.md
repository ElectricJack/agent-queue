# Default Rule Samples

<!-- aq:historical -->
> **Historical sample.** Illustrative content that nothing installs or loads. It
> was written for an earlier runtime, so copying it will not reproduce the
> behaviour it describes. Start at [the documentation home](../README.md); see
> [historical material](../history/README.md).

These files are historical documentation samples, not default rules consumed
by the application. No vault-layout or default-playbook installer copies them.

They remain available as reference material only and are intentionally outside
`src/`, which keeps the runtime Markdown-source corpus limited to files with a
defined installation path.
