# Example Playbooks

<!-- aq:historical -->
> **Historical sample.** Illustrative content that nothing installs or loads. It
> was written for an earlier runtime, so copying it will not reproduce the
> behaviour it describes. Start at [the documentation home](../README.md); see
> [historical material](../history/README.md).

These are documentation samples, not shipped runtime playbooks. They are not
installed by `ensure_vault_layout`, `ensure_default_playbooks`, or
`ensure_default_agent_type_playbooks`.

Copy and adapt a sample into a vault playbooks directory to opt in. The
samples preserve older authoring examples and are intentionally kept outside
`src/` so the runtime playbook-source corpus contains only installed sources.
