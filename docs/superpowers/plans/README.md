# Feature plans (historical)

<!-- aq:historical -->
> **Historical implementation plans.** Each file is how one feature was planned
> before it was built, kept as the record of the decision. Checklists here are
> not work to do, and a plan's file paths are the paths that existed the day it
> was written. Start at [the documentation home](../../README.md).

A plan is the *how*: packages, commit order, the tests each step must add, the
acceptance the author signed up to. Its matching design document — the *what* and
*why* — is normally in [`../specs/`](../specs/README.md) under the same date and
slug.

Dates come from the filename. A plan whose feature was later re-scoped or
abandoned is still listed: that is the point of keeping it.
